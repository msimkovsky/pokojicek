# Pokojíček

3D vizualizace a montážní podklady pro pracovní stěnu v dětském pokoji (IKEA Kallax, Trofast, Skådis, Lack, Flisat + dubová deska na míru).

Otevřít: https://msimkovsky.github.io/pokojicek/

Jeden soubor `index.html` (Three.js z CDN): 3D model s ovladači a kontrolou kolizí, přehled materiálu a nářadí, montážní výkres generovaný z aktuálního nastavení.
